# Reactive Omni Buildathon – rules summary (read 2026-11-18)

* Dates: submissions 5 Nov – **5 Dec 2026, 20:00 UTC**. DoraHacks: https://dorahacks.io/hackathon/reactive-omni-buildathon
* Prizes (paid in REACT, USD-denominated): Every Second Counts $2,000 + $250; **Set It and Forget It $2,000 + $250**; Reactive Meets AI $1,000.
* Judging, 1–5 each, equally weighted: **Execution** (reactive txs and callbacks on-chain, otherwise not scored further),
  **Integration** (reactive contract does real work), **Usefulness**, **Craft** (readable code, working demo, docs).
* Submit: public repo link, deployed contract addresses, a few tx hashes showing the full loop (origin event → callback),
  demo video under 3 minutes.
* Ground rules: repo public and open-source at submission; built during the event (prior work only as a dependency);
  Every Second Counts must run on Lasna (others may use Lasna or Reactive mainnet); on Base Sepolia use timestamps,
  not block counts.
